# Política de seguridad

## Versiones soportadas

Este proyecto no usa versiones etiquetadas: se despliega de forma continua
desde la rama `dev` (integración) y `main` (release). Solo se da soporte de
seguridad a lo que esté en esas dos ramas.

## Reportar una vulnerabilidad

Si encontrás una vulnerabilidad de seguridad, reportala de forma **privada**
usando [GitHub Security Advisories](https://github.com/pipetboy2001/retroAchievements-Download-games/security/advisories/new)
("Report a vulnerability" en la pestaña Security del repo) en vez de abrir un
issue público.

Incluí, si es posible:

- Pasos para reproducir el problema.
- Impacto (qué se puede hacer con esto).
- Versión/commit afectado.

Vas a recibir una respuesta inicial en un plazo razonable. Este es un
proyecto de código abierto mantenido por una sola persona en su tiempo
libre, así que los tiempos de respuesta pueden variar.

## Alcance

Esta herramienta no aloja, modifica ni redistribuye ROMs: solo genera enlaces
de descarga hacia archive.org a partir de un hash. Vulnerabilidades fuera de
alcance (reportalas directamente al tercero correspondiente):

- Contenido o disponibilidad de archive.org.
- Cuentas de RetroAchievements (autenticación/datos de usuario en su propia
  plataforma).
